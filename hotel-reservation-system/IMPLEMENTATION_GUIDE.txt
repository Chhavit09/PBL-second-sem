TROUBLESHOOTING
===============
Q: Program won't compile
A: Ensure all .h files are in src/ directory
   Use: cd src && gcc -o hotel_system *.c

Q: Login rejected
A: Check default: admin/admin123
   Verify data/credentials.txt exists

Q: No data persists
A: Check data/ directory created
   Verify file permissions (chmod 755 data/)

Q: Room not available error  
A: Check-out date must be after check-in
   Cannot overlap with existing reservations
