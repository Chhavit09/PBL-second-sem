PROJECT OVERVIEW
================================================================================
This is a Hotel Management System built in C that manages hotel operations 
including reservations, room management, staff authentication, reporting, 
and guest bookings. The system uses file-based data storage and provides 
both guest and admin functionalities.

SYSTEM ARCHITECTURE
================================================================================
The system follows a modular design with clear separation of concerns. 
All modules interact through a central main.c file that orchestrates the 
application flow.

1. STRUCTURES MODULE (structures.h)
================================================================================
PURPOSE: 
    Defines all data structures used throughout the system

KEY DATA STRUCTURES:

    • User
      - username (MAX_USERNAME_LENGTH characters)
      - password (MAX_PASSWORD_LENGTH characters)
      Usage: Authentication and credential validation

    • Room
      - roomNumber (integer identifier)
      - roomType (30 characters - Single/Double/Suite)
      - price (float - price per night)
      - isOccupied (integer flag - 0 or 1)
      Usage: Hotel room inventory management

    • Reservation
      - reservationID (unique identifier)
      - guestName (up to 100 characters)
      - email (up to 100 characters)
      - phone (up to 20 characters)
      - roomNumber (integer)
      - checkInDate (15 character format)
      - checkOutDate (15 character format)
      - totalPrice (float)
      - status (integer - booking status)
      Usage: Guest reservation records

    • Payment
      - reservationID (links to reservation)
      - amount (float - payment amount)
      - paymentDate (15 character format)
      - paymentMethod (30 characters)
      Usage: Payment tracking

DEFINED CONSTANTS:
    - MAX_USERNAME_LENGTH: 50
    - MAX_PASSWORD_LENGTH: 50
    - MAX_GUEST_NAME_LENGTH: 100
    - MAX_DATE_LENGTH: 15
    - MAX_EMAIL_LENGTH: 100
    - MAX_PHONE_LENGTH: 20
    - MAX_ROOMS: 100
    - MAX_RESERVATIONS: 500

================================================================================
DATA STORAGE & FILES
================================================================================

The system uses file-based persistence with the following files located in 
the data/ directory:

1. credentials.txt
   - Stores user login credentials
   - Format: username,password (one user per line)
   - Usage: User authentication

2. staff_credential.txt
   - Stores staff member credentials
   - Format: username,password (one staff per line)
   - Usage: Staff login and management

3. reservations.txt
   - Stores all guest reservations
   - Format: CSV with reservation details
   - Fields: ID, GuestName, Email, Phone, RoomNumber, 
            CheckInDate, CheckOutDate, TotalPrice, Status
   - Usage: Reservation management and reporting

4. rooms.txt
   - Stores hotel room inventory
   - Format: CSV with room details
   - Fields: RoomNumber, RoomType, Price, IsOccupied
   - Usage: Room management and availability checking

5. output/ directory
   - Stores generated reports
   - Contains occupancy reports and revenue reports
   - Format: Text files with report data
